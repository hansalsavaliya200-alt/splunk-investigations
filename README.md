# 📌 About This Repository

This repository contains **10 hands-on SOC investigations** performed using **Splunk Enterprise**. Each investigation simulates realistic cyber attacks against Windows systems and focuses on threat hunting, incident response, log analysis, Windows Event Logs, MITRE ATT&CK mapping, and malware investigation.

The objective of this repository is to demonstrate practical Blue Team skills and build a professional SOC Analyst portfolio.
