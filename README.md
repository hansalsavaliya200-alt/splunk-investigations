# 🛡️ About This Repository

This repository showcases **11 hands-on SOC investigations** performed using **Splunk Enterprise** against Windows environments.

Each investigation simulates realistic cyber attacks and demonstrates the complete incident investigation process including:

* Threat Hunting
* Windows Event Log Analysis
* Incident Response
* Digital Forensics
* IOC Identification
* Attack Timeline Reconstruction
* MITRE ATT&CK Mapping
* Blue Team Detection Engineering

The goal of this project is to build a practical SOC Analyst portfolio by analyzing realistic attack scenarios and documenting professional investigation reports.
